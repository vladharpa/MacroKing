Acesta este proiectul meu neterminat, facut in vacanta de dupa anul 1 pe timpul facultatii.
Este o aplicatie de calculat macronutrienti si recomandat retete. 
Include baze de date pentru register si log in legate de formuri in meniul de log in/register complet functionale pentru viitorii clienti, server local cu javascript si JS. 
Din cate imi amintesc erau mai multe pagini, iar una era pentru search-ul alimentelor si afisarea lor. Ar fi trebuit sa gasesc un API pentru recomandarea retetelor si sa cumpoar o baza de date, lucruri pe care nu le-am facut, dupa care am abandonat proiectul 
Interfata a fost creata cu bootstrap, iar animatiile au fost facute in JS.
